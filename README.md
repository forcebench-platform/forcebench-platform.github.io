# forcebench-platform.github.io

The ForceBench project website, served by GitHub Pages at
https://forcebench-platform.github.io/.

The benchmark code lives at
https://github.com/forcebench-platform/ForceBench — this repository holds
only the static site. The leaderboard page reads
`results/leaderboard.json` from the code repository at page load, so
leaderboard updates belong there, not here.
